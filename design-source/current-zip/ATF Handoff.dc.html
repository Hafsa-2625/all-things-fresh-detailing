One rule above all others

If a content requirement will not fit an existing component, stop and ask. Do not invent a new public design to accommodate it.

The public site looking identical after the build is the definition of success, not a constraint on it. Everything in these files is arranged so that outcome is the default and a regression is the thing that takes effort.

These are design and specification artifacts. Standing up the actual CMS, CRM, database, authentication, payment processing, Playwright runner and hosting is development work outside this project.
